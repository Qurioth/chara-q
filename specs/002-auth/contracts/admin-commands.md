# Contract: 管理者のコマンド（Taskfile の `admin:*`）

招待コードの発行以外の管理者の操作は、`apps/api/cmd/admin` のコマンドで行う（Clarifications Q3）。
入口は Taskfile だけにする（constitution のツールとタスク）。

## 共通

- 接続先は `DATABASE_URL`。タスクは `apps/api/.env` を読む。本番の DB に対して実行するときは、
  シェルで `DATABASE_URL` を設定してから実行する（Task の `dotenv` がシェルの値を上書きしないことを、
  実装のときに確かめる。research R14）。
- 実行の最初に、接続先を `接続先: <ホスト>/<データベース名>` の形で標準エラー出力に出す。
  パスワードなどの接続の秘密は出さない。
- 成功したら終了コード 0、失敗したら 1。メッセージは日本語で標準エラー出力に出す。結果
  （コード、一覧）は標準出力に出す。
- ログイン ID の指定は、大文字と小文字を区別しない（FR-015）。
- 入力の規則・ハッシュ・セッションの削除は、web の操作と同じ `internal/auth` の処理を使う。
- パスワードの値・コードのハッシュは出力しない。

## タスク

| タスク | 引数 | 処理 | 出力 |
|---|---|---|---|
| `task admin:create` | `-- -login-id <ID> -display-name <表示名>` | 管理者ユーザーを作る。パスワードは画面に出さずに 2 回入力させ、一致しなければ失敗する。既に使われているログイン ID なら失敗し、既存のユーザーは変えない | `管理者を作りました: <ログイン ID>` |
| `task admin:users` | なし | ユーザーの一覧を作成日時の順に出す | 表: ログイン ID、表示名、管理者、状態（有効 / 無効）、作成日時 |
| `task admin:reset-code` | `-- <ログイン ID>` | 再設定コードを発行する。前の未使用のコードは使えなくなる。無効なユーザーには発行しない | 再設定コード（4 文字ごとにハイフン）と有効期限 |
| `task admin:disable` | `-- <ログイン ID>` | ユーザーを無効にし、セッションをすべて消す。既に無効なら何もせず成功する | `無効にしました: <ログイン ID>（切ったセッション: <件数>）` |
| `task admin:enable` | `-- <ログイン ID>` | ユーザーを有効に戻す。既に有効なら何もせず成功する | `有効にしました: <ログイン ID>` |

- `admin:create` のタスクには `interactive: true` を付ける。
- 端末でないとき（テストや CI）は、パスワードを標準入力から 2 行で読む。コマンドの引数と環境変数
  では受け取らない（FR-041）。

## 失敗のメッセージ（例）

| 場面 | メッセージ |
|---|---|
| ログイン ID が規則に合わない | `ログイン ID は半角英数字・_・- の 3〜32 文字にしてください` |
| ログイン ID が使われている | `ログイン ID が既に使われています: <ID>` |
| ユーザーが見つからない | `ユーザーが見つかりません: <ID>` |
| 無効なユーザーに再設定コード | `無効なユーザーには再設定コードを発行できません: <ID>（先に admin:enable を実行してください）` |
| パスワードが一致しない | `パスワードが一致しません` |
| DB に接続できない | `DB に接続できません: <理由>` |
